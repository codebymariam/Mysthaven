# HCI design

Mysthaven was developed for COSC 452. The design work spans player personas, interaction flows, prototype iteration, and formative evaluation.

| Principle | Application |
| --- | --- |
| Direct manipulation | Drag clock hands, fit puzzle pieces, and connect wires. |
| Natural mapping | Theme the action around the room and object being used. |
| Error prevention | Disable incomplete submissions and require vote confirmation. |
| System visibility | Show task progress, ability cooldowns, voice range, and meeting deadlines. |
| Recognition | Keep task references visible and show roles with explicit goals. |
| Flexible interaction | Provide keyboard and touch controls, plus text and supported voice channels. |
| User control | Offer settings, cancel, hint, and reset where appropriate. |
| Closure | Confirm task completion, voting outcomes, and XP awards. |
