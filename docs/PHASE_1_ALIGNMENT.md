# Phase 1 alignment

| Design goal | Final prototype response |
| --- | --- |
| Help newcomers understand their role | Dedicated role reveal and explicit objectives. |
| Support fast decisions for experienced players | Role-aware HUD, hotkeys, and private ability feedback. |
| Support exploration and legible choices | Themed room tasks and color-plus-symbol CCTV sockets. |
| Prevent stalled meetings | Separate discussion and voting, show the deadline, and confirm choices. |

## Task redesigns

| Task | October to November change |
| --- | --- |
| Light the Chandeliers | Replaced a generic sequence with transferring flame to visible wicks. |
| Synchronize the Clock | Uses clock-hand manipulation with visible targets and alternate controls. |
| Scan Vitals | Rebuilt the scan around visible stages and completion feedback. |
| Repair Wiring | Uses visible leads and terminals with reversible placement errors. |
| Restart the Generator | Shows staged fuse, priming, voltage, and lever controls. |
| Restore Passage Lights | Uses a visible power path and circuit diagnostics. |

The comparison describes design changes. See [the formative study](USABILITY_TESTING.md) for the measured outcomes.
