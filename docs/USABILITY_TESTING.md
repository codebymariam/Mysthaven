# Formative usability testing

| Version 3 study measure | Result |
| --- | ---: |
| Participants | 5 |
| Applicable task attempts | 22 |
| Independent completion | 20/22 (90.9%) |
| Completion with help allowed | 22/22 |
| Mean ease rating | 1.05/5 (1 = very easy) |

The classroom study covered joining and role comprehension, room tasks, nearby communication, ability unlock, meetings, and enemy release. One participant received a voice-range hint and one voted after a prompt.

The study informed feedback about voice audience, voting deadlines, and repeated enemy releases. Participants received the Survival Guide. Role assignments affected which tasks were applicable, and timing boundaries varied. These observations support formative design decisions. Cross-device usability, later features, and real-world retention need further evaluation.
