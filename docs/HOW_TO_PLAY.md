# How to play

[Launch Mysthaven on itch.io](https://mariam04.itch.io/mysthaven), choose **Run game**, then **Play**. A match supports 4–8 players.

1. Enter a display name. Hosts choose **Create Lobby** and share the room code. Guests choose **Join With Code** or browse **Public Lobbies**.
2. Choose a character at the lobby mirror and ready up. The host can review **Game Settings** before starting.
3. Check the role reveal. Crew complete tasks and report bodies. Impostors use fake objectives to blend in and can summon Veil enemies. Discuss reports and confirm a vote or skip.

## Controls

| Key | Action |
| --- | --- |
| WASD or arrows | Move |
| E / R | Interact / report |
| M or Tab | Map |
| Shift | Dodge |
| Q | Crew Strike or impostor Kill |
| C | Character ability or Scanner |
| G | Veil Summoning |
| X | Vigilante shot |
| V | Push to talk where available |
| Esc | Toggle the relevant menu or overlay |

The web build supports keyboard and mouse on desktop and touch on iPad. Lobby and meeting text chat are available.
